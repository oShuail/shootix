# مصنع روائع الإنتاج للبلاستيك — الموقع الإلكتروني
### RAWAE AL INTAJ PLASTIC FACTORY — website

موقع تعريفي ثنائي اللغة (عربي / إنجليزي) لمصنع روائع الإنتاج للبلاستيك — الرياض.
موقع ثابت (HTML/CSS/JS) بدون أي إطار عمل أو خطوة بناء: افتحه ويعمل.

A bilingual (Arabic / English) site for RAWAE AL INTAJ Plastic Factory, Riyadh.
Plain static HTML/CSS/JS — no framework, no build step.

---

## التشغيل محليًا · Run locally

```bash
# أي خادم ملفات ثابت · any static file server
npx serve .
# ثم افتح · then open  http://localhost:3000
```

فتح `index.html` مباشرة من الملفات يعمل أيضًا، لكن يُفضَّل الخادم المحلي.

## ★ استبدال الصور · Replacing the images

كل الصور الحالية في `assets/img/ph/` **مؤقتة** — رسومات مصمّمة تحمل علامة
«PLACEHOLDER» لتوضيح مكان كل صورة. لاستبدالها:

> **احتفظ باسم الملف كما هو، والتزم بنسبة الأبعاد** — وسيبقى التصميم كما هو تمامًا.
> Keep the filename, match the aspect ratio, and the layout stays identical.

| الملف · file | المقاس المقترح | النسبة | الصورة المطلوبة |
|---|---|---|---|
| `video/hero.mp4` | 1920×1080 | 16:9 | **فيديو الهيرو** — اختياري. انظر القسم التالي |
| `ph/hero.jpg` | 1700×1150 | 3:2 عريض | واجهة المصنع أو خط الإنتاج — تظهر قبل تشغيل الفيديو وبديلًا عنه |
| `ph/about.jpg` | 1000×1300 | 4:5 طولي | مخزون البكرات أو صالة الإنتاج |
| `ph/prod-shopping.jpg` | 900×900 | 1:1 | أكياس تسوق |
| `ph/prod-refuse.jpg` | 900×900 | 1:1 | أكياس بلدية / نفايات |
| `ph/prod-food.jpg` | 900×900 | 1:1 | أكياس حفظ الأغذية |
| `ph/prod-film.jpg` | 900×900 | 1:1 | أفلام بالبكرة |
| `ph/prod-custom.jpg` | 900×900 | 1:1 | منتج مُصنَّع حسب الطلب |
| `ph/prod-print.jpg` | 900×900 | 1:1 | أكياس مطبوعة بشعار عميل |
| `ph/step-1.jpg` … `step-6.jpg` | 1100×820 | 4:3 | صورة لكل مرحلة: الخامة، نفخ الفيلم، الطباعة، القص واللحام، الفحص، التعبئة |
| `ph/quality.jpg` | 1900×950 | 2:1 عريض | لقطة واسعة لصالة الإنتاج (تُستخدم كخلفية) |
| `ph/sector-*.jpg` (٦ صور) | 760×950 | 4:5 طولي | صورة تمثل كل قطاع: تجزئة، أغذية، جملة، مصانع، منشآت، لوجستيات |
| `ph/gallery-1..4.jpg` | 1200×800 | 3:2 | أربع لقطات من داخل المصنع |

**ملاحظات مهمة**

- الصور تُقصّ من المنتصف (`object-fit: cover`) — اجعل الموضوع في وسط الصورة.
- استخدم `.jpg` بجودة 75–85٪. يفضَّل ألا يتجاوز الملف الواحد ~300 كيلوبايت.
- الصور الداكنة قليلًا تناسب الهوية أكثر، والنص الأبيض فوقها يبقى مقروءًا.
- في ملفات HTML كل مكان صورة معلَّم بتعليق `<!-- IMAGE SLOT · المقاس — الوصف -->`
  للبحث السريع.
- **مهم:** حدِّث نص `alt` لكل صورة بعد استبدالها — يفيد الوصولية وأرشفة جوجل.
- عند إضافة/حذف صور، حدِّث `scripts/make-placeholders.js` أو احذفه — فهو للتوليد فقط.

## فيديو الهيرو · The hero film

الهيرو يقبل فيديو خلفيًا اختياريًا. ضع الملف في `assets/video/hero.mp4` ويعمل
تلقائيًا — لا حاجة لتعديل أي كود.

| البند | القيمة |
|---|---|
| المقاس | 1920×1080 (16:9) |
| المدة | 12–20 ثانية، مقطع مكرَّر |
| الصيغة | MP4 / H.264 — ويمكن إضافة `hero.webm` بجانبه |
| الحجم | ≤ 4 ميجابايت |
| الصوت | بدون (يُشغَّل مكتومًا دائمًا) |

**كيف يتصرف الموقع:** الصورة الثابتة `ph/hero.jpg` هي الطبقة الأساسية وتظهر فورًا.
الفيديو يُعرَض فوقها فقط بعد أن يبدأ التشغيل فعليًا — فإن كان الملف غير موجود، أو منع
المتصفح التشغيل التلقائي، أو كان الجهاز في وضع توفير البيانات، أو فعّل المستخدم
«تقليل الحركة»، تبقى الصورة كما هي بلا وميض ولا شاشة سوداء.

**عند التصوير:** اترك وسط الكادر هادئًا لأن العنوان يجلس فوقه، ولا تُظلم التدرج —
الموقع يضيف طبقة داكنة من عنده. ولا تضع نصًا داخل الفيديو، فالموقع ثنائي اللغة والنص
سيتعارض مع أحد الاتجاهين.

> الملف الموجود حاليًا في `assets/video/hero.webm` **مؤقت**، مولَّد من الصور المؤقتة
> لتجربة الحركة فقط. احذفه عند تسليم الفيديو الحقيقي.

## تعديل المحتوى · Editing content

المحتوى مكتوب مباشرةً داخل ملفي HTML — لا توجد قاعدة بيانات ولا لوحة تحكم.

- النص العربي: `index.html`
- النص الإنجليزي: `en/index.html`
- **أي تعديل في نص أو منتج يجب أن يُطبَّق على الملفين معًا** ليبقى الموقع متطابقًا.

### بيانات التواصل

الأرقام والبريد مكتوبة في عدة مواضع (الهيدر، النموذج، قائمة التواصل، الفوتر،
زر واتساب العائم، شريط الجوال). عند التغيير، ابحث واستبدل في **كلا** الملفين:

| القيمة الحالية | المواضع |
|---|---|
| `966509196057` | روابط `wa.me` + `data-whatsapp` في النموذج |
| `+966509196057` / `+966545380389` | روابط `tel:` |
| `rawae.plastic@gmail.com` | روابط `mailto:` + `data-email` في النموذج |
| `https://rawae-plastic.com` | وسوم `canonical` و`hreflang` و`og:` و`sitemap.xml` و`robots.txt` |

### نموذج طلب عرض السعر

لا يوجد خادم خلفي. عند الإرسال يقوم النموذج بتجميع بيانات الطلب في رسالة منسّقة
ثم:

- **إرسال عبر واتساب** → يفتح محادثة جاهزة على الرقم في `data-whatsapp`
- **إرسال بالبريد** → يفتح برنامج البريد برسالة جاهزة إلى `data-email`

لتحويله لاحقًا إلى نموذج يُرسل تلقائيًا، يمكن ربطه بخدمة مثل Formspree أو
Web3Forms دون تغيير التصميم.

## الألوان والخطوط · Design tokens

كل ألوان الهوية معرَّفة في أعلى `assets/css/site.css` داخل `:root` —
تغيير الذهبي مثلًا يتم من مكان واحد:

```css
--gold: #B58B3C;   /* الذهبي الأساسي، مستوحى من الشعار */
--paper: #F7F3EA;  /* الأوف وايت */
--ink: #14130F;    /* الفحمي الصناعي */
```

**الخطوط:** IBM Plex Sans Arabic + IBM Plex Sans + IBM Plex Mono، مستضافة
ذاتيًا في `assets/fonts/` (لا اعتماد على Google Fonts، وأسرع في التحميل).
الخطوط مرخّصة تحت [SIL Open Font License 1.1](https://scripts.sil.org/OFL).

**الشعار:** `assets/img/logo-mark.svg` هو إعادة رسم متجهية للشعار المرسل.
إن توفّر الملف المتجه الأصلي (AI/EPS/SVG) من المصمم، يُفضَّل استبداله به.

## النشر · Deploying

الموقع ثابت بالكامل، فيعمل على أي استضافة:

**Vercel** (يوجد `vercel.json` جاهز بإعدادات التخزين المؤقت)
```bash
npx vercel --prod
```

**Netlify** — اسحب مجلد المشروع إلى لوحة التحكم، أو اربط المستودع.

**GitHub Pages** — Settings → Pages → Deploy from branch → `main` / `root`.

**استضافة عادية** — ارفع كل الملفات عبر FTP كما هي.

بعد ربط النطاق، استبدل `https://rawae-plastic.com` بالنطاق الفعلي في
`index.html`, `en/index.html`, `sitemap.xml`, `robots.txt`.

## ملاحظة على المحتوى · A note on the copy

النصوص كُتبت لتصف قدرات المصنع **دون ذكر أي أرقام أو شهادات لم تُزوَّد بها**
(لا طاقة إنتاجية، ولا سنوات خبرة، ولا شهادات جودة). المواصفات معروضة كبنود
«حسب الطلب» لأنها فعلًا تُحدَّد مع العميل.

إن رغبتم بإضافة أرقام حقيقية — الطاقة الإنتاجية، سنة التأسيس، عدد العملاء،
شهادات (SASO / ISO / هيئة الغذاء والدواء) — فهي إضافات قوية جدًا للمصداقية،
وأماكنها الطبيعية: شريط الهيرو، وقسم «لماذا روائع الإنتاج»، وقسم الجودة.

The copy deliberately avoids production figures, founding dates and
certifications, because none were provided. Real numbers are the single
biggest credibility upgrade available to this page — send them over and they
slot straight into the hero strip, the reasons band and the quality section.
